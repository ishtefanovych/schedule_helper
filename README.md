# schedule_helper
This is a Telegram bot built with Java and Spring Boot that shows current weather and university class schedules. It uses the TelegramBots API for user interaction and fetches data from external REST APIs. The code follows a layered architecture: a controller routes messages, while the service layer handles external requests and data processing.
To get the bot up and running, simply launch the application and open the bot in Telegram by its handle, @ShtefanScheduleBot.
